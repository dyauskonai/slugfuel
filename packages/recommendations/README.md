Future home for generating realistic plates, enforcing exclusions, scoring nutrient fit, and explaining alternatives.

Accept validated menu data and user preferences as inputs. Return ranked plates and explicit explanations. Keep network and database work outside this package. Start with deterministic rules; evaluate learning-based ranking later against the measured baseline.

Test realistic portions, impossible targets, exclusions, missing data, and ranking consistency. This is a directory boundary, not an initialized package.
